# Set up DropIn AI Editor

Open this repo in your agent and say **“Set up DropIn AI Editor for me.”**

The agent follows the [guided onboarding](plugins/dropin-ai-editor/docs/ONBOARDING.md): it walks you
through getting your own pipeline credentials, configuring brands and delivery routes, and
checking a first local clip. [All keys and account connections](plugins/dropin-ai-editor/docs/CONNECTIONS.md).

The same guide ships inside the plugin, so checkout and plugin installations share one setup flow.
